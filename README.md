# Diseño de Software

## Presentación

Este repositorio reúne los trabajos prácticos, ejercicios y actividades desarrollados durante la materia **Diseño de Software**.

Su objetivo es organizar y conservar las implementaciones realizadas a lo largo de la cursada, incluyendo el código fuente, la documentación de cada ejercicio y las capturas de los resultados obtenidos durante su ejecución.

El repositorio se encuentra dividido en tres unidades: **Unidad 2, Unidad 3 y Unidad 4**. Cada una cuenta con una estructura de carpetas propia, organizada por actividades y ejercicios para facilitar la navegación, la identificación de los trabajos y su posterior revisión.

## Organización del repositorio

### Unidad 2

Contiene los ejercicios y actividades correspondientes a la segunda unidad de la materia.

Los trabajos se organizan en carpetas individuales, identificadas mediante su correspondiente numeración. Actualmente, se encuentra incorporado el ejercicio `2.1.1`, y la estructura se irá completando a medida que se incorporen las demás actividades.

### Unidad 3

Reúne los ejercicios y actividades correspondientes a la tercera unidad.

Al igual que en las demás unidades, cada actividad cuenta con su propia carpeta para mantener separados los archivos de implementación y su documentación. Su contenido se irá incorporando progresivamente.

### Unidad 4

Contiene dos grupos de ejercitación:

- **4.E1:** incluye diez ejercicios, identificados desde `4.E1.01` hasta `4.E1.10`.
- **4.E2:** incluye diez ejercicios, identificados desde `4.E2.01` hasta `4.E2.10`.

Cada ejercicio se encuentra organizado en una carpeta independiente y cuenta con sus respectivos archivos de código fuente, documentación y recursos complementarios.

## Organización de cada ejercicio

Cada ejercicio se desarrolla en una carpeta independiente. Dentro de ella se pueden encontrar los siguientes elementos:

- **Código fuente:** archivos Java que contienen las clases y la implementación de la solución.
- **README.md:** documentación individual que explica el problema planteado, el objetivo de aprendizaje, los conceptos aplicados, la estructura del código y su funcionamiento.
- **Capturas de pantalla:** imágenes que permiten visualizar los resultados obtenidos durante la ejecución.

Esta organización permite que cada actividad tenga su propio espacio de trabajo y documentación, sin mezclar archivos de distintos ejercicios.

## Herramientas utilizadas

- **Java:** lenguaje de programación utilizado para desarrollar las soluciones.
- **IntelliJ IDEA:** entorno de desarrollo integrado utilizado para escribir, organizar y ejecutar los programas.
- **Git:** sistema de control de versiones utilizado para registrar los cambios realizados.
- **GitHub:** plataforma utilizada para alojar el repositorio y mantener organizado el material de la materia.

## Objetivos del repositorio

- Organizar los trabajos prácticos y ejercicios de las tres unidades.
- Aplicar los conceptos teóricos mediante implementaciones prácticas.
- Mantener el código fuente y la documentación de manera ordenada.
- Facilitar la comprensión y revisión de cada actividad.
- Registrar el progreso de los trabajos realizados durante la cursada.
- Conservar un espacio de consulta para los ejercicios y sus respectivas soluciones.

## Consideraciones finales

Este repositorio forma parte del proceso de aprendizaje de la materia **Diseño de Software**. A través de las actividades de las Unidades 2, 3 y 4 se busca poner en práctica los conocimientos adquiridos, fortalecer las habilidades de programación y comprender la importancia de aplicar principios y patrones de diseño para desarrollar soluciones de software organizadas, comprensibles y mantenibles.
